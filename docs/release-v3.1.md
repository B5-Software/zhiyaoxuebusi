# v3.1.0 · 同一张账本，同一条时间线

大学和社会的区域地图现在占满主视图，与高中一样拖拽、触屏双指缩放、浮动地点和信息卡。区域切换后直接回到地图，地点按自己的功能进入；原始13张资源保留1672×941，资源字节没有修改。默认150%，屏幕外行动提示和本周用完后的角标隐藏继续生效。

交易所增加专业K线台：日/周/四周OHLC、成交量、MA5/MA20、指针及键盘查看、新闻标记、自选行情、持仓成本、成交历史、逐仓追加/移出保证金、资金费及交割。虚拟深度明确说明展示性质。现货费用最低0.01元，拒绝零碎到分以下的资金变动。

新闻每两周发布一则，最近六则不重复；报道改变价格漂移和交易量，随机冲击仍能反转方向。报道中的租金变化计入后续每周账单，招聘报价影响新签合同，旧合同保留原价。市场始终是本地游戏模拟。周内不利高低价触及强平条件即结算，不会因收盘反弹恢复仓位。

## 系统衔接

- 日历接续2025年开场。原毕业相处期间不能独立跳月领取生活费，人生时钟按周统一推进。大学按入学时点、208周、160学分判断毕业。
- 学生工作按20小时兼职折算；自动日程兼顾课程、工作与休息。欠薪只有完成排班才记为应收，追索跨三周到账；缺勤会结束合同。退休取决于缴费记录。
- 租金持续调整。生活现金缺口影响饮食和压力；救助、助学及票据审核跨四周处理，先抵扣欠款。待办和回执保存在账本与手帐。
- 家庭收入来自伴侣工作与照护分工，可暂缓排班；伴侣也会退休。孕育12/24/36周有检查入口，分开保留共同照护责任。婚姻长任务从登记周计时。
- 孩子积累自己的照护、技能、学分与身体记录，读够四年且满足学分才有本科。继续孩子人生时，未入高中跳至15岁，已经高中或成年保持实际年龄；15至18岁有独立的高中阶段，下一段地图到成年后开放。遗产扣除债务并保留在世伴侣份额。
- 医院保存数字结果、疑似和确认目标；影像/活检/骨髓指征有13周有效期，代谢检查需跨周确认。只有原定12类病况。状态区分代偿/负荷/失代偿/危急；停药、逾期复查和肿瘤复发能打破稳定。肿瘤六阶段疗程和缓解随访分别记录，复查不会重置疗程。
- 基础保险按模拟年度累计起付，商业等待期与既往诊断除外清单分别结算。急救在无现金、无行动时仍可进入。
- 事件优先未读，耗尽后按各事件52周冷却选择符合阶段与现实条件的故事；冷却不依赖会滚动删除的近期记忆。

## 存档升级

存档键及GameState版本保持兼容，人生子状态升级schema2。保留旧现金、资产、条件和人物关系。旧现货成本未保存，按升级时标记价建立基线；旧行情只有周收盘价，历史日线插值重建，不提供历史成交量。界面明确提示这两项限制。旧检查文字保留，但进一步检查需要新的结构化指征。
