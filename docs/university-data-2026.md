# 大学图鉴数据说明（2026 届 · 陕西物理类）

游戏内大学图鉴收录约 300 所在陕西招生的本科院校。本文档说明数据字段、来源、口径与换算方法；逐校明细见 [`university-data-2026.json`](university-data-2026.json)。

## 字段

| 字段 | 含义 |
| --- | --- |
| `threshold` | 游戏门槛。以 2026 年陕西物理类普通本科批投档最低分为准；缺 2026 数据时用 2025 年位次换算到 2026 年等位分 |
| `rank` / `rankYear` | 参考位次及其年份（2026 或 2025），显示在院校卡片上 |
| `source` | 学校官网（用于卡片外链） |
| `type` | 985 / 211 / 双一流 / 本科（学校最高层次标签） |
| `level` | 公办 / 民办 / 中外合作 |

## 数据来源

1. **2026 年陕西省本科批投档线汇总（公开整理，非官方发布）**：覆盖约 100 所重点院校，用于优先填充 2026 直采数据。
2. **各校本科招生网**：2026/2025 年分省分专业录取公示。
3. **公开志愿数据平台**：2025 年陕西物理类院校各专业组最低分与最低位次。
4. **公开录取数据汇总**：2025 年陕西省内院校最低分与位次表。
5. **陕西省教育考试院一分段统计表**：2026 与 2025 年物理类一分一段表，用于位次换算与数据校验。

## 口径与处理

- 只取**普通类本科批**；排除提前批、专项计划、艺术体育类与军警院校（军校警校与艺术体育院校整体不收录）。
- 学校分数取该校在陕**普通专业组中的最低分**；部分院校的较低分组可能包含中外合作、ICC 等项目，卡片以“游戏门槛”标注，不区分具体专业组。
- 个别院校在陕西没有本科批普通类数据（例如综合评价、提前批为主的院校），其参考数据取自最接近的批次（提前批普通类 / 综合评价 / 中外合作办学 / 国家专项计划），仅供游戏参考。
- **2025 → 2026 换算**：把 2025 年最低位次放到 2026 年一分段表中，取同位置的分数作为 2026 等位分。这样不同年份的数据在同一把尺子上比较。
- 数据校验：所有“分数/位次”对都会与对应年份的一分段表核对（位次必须落在该分数的累计区间内），不一致的记录会被修正或降级处理。

## 免责声明

所有分数门槛与参考位次仅用于游戏内的模拟投档，**不能用于真实志愿填报**。现实决策请核对当年招生章程、选科要求、位次、批次与招生计划。
