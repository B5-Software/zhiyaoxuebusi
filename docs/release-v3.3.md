# v3.3.0 · 从人生的哪一页开始

新开局可选择高中、大学、社会、退休。高中18岁、120元，继续真实高三和高考流程；大学18岁、3000元，从所选院校专业的零学分开始，仍需208周与160学分毕业；社会22岁、5000元，可选择本科背景或职业实践，未预设工作、伴侣和孩子；退休60岁、20000元，以明确展示的30年工作与缴费背景领取模拟收入，并继续年龄与健康变化。大学之后三个地图均可自由切换。

直接从人生阶段开局有独立startStage字段，高考成绩保持空值，不伪造考试答案或剧情历史。严格区分正常高中毕业与直接开局的存档，旧档缺少字段时默认为高中。新故事重新显示对应指引；开局配置只有点击开始后才替换当前自动存档。姓名、男女主、院校专业与学历选项进入后续状态。

按钮保留正常高度与内边距，操作组至少12至16px间距，窄容器换行。导航入口按可用宽度整项分组，左右按钮、横向滚动、键盘和焦点导航均可用，十四个入口保持正常按钮尺寸与完整显示。左侧任务和账本分别成组，次要身体说明使用紧凑摘要，信息卡不再被flex压扁。地点按侧栏、新闻栏、地图工具的实际尺寸避让；放不下的行动地点转为独立边缘箭头，保留角标与按钮间距。较矮的地图将本周安排打开为可滚动窗口，长姓名也不会挤到账户按钮。模态框使用一致的屏幕边距与可滚动正文。

验证：154项逻辑测试；高中109、人生57、连续故事52、人生旅程6、四阶段真实开局与间距155、完整导航及地图角标70，共449项浏览器检查。320×568、390×844、768×1024、1440×1000、844×390横屏。包含四年大学实际毕业、退休收入、跨周剧情、刷新恢复、下一代、旧档与非法状态拒绝，以及侧栏展开和收起时所有可行动地点的完整入口。生产构建、TypeScript、启动重试与GitHub子路径离线打开通过。线上验证见deployment.json。
