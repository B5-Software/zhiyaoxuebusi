# v3.2.0 · 图标、画面与连续人生故事

大学、社会沿用高中GameIcon的原生64×64手绘矢量语言。新增10种彩色图标，导航、地图浮动地点、资源、工作、医院检查、任务和小游戏使用与功能相符的图案；纸张卡片、留白、双层描边和手机横向导航同步调整。

新增一条主线、八条支线，共36章、72个选择后果。每章有场景叙述、人物对白、选择与结果；主线至少208周，支线12至24周。内容包括四年大学生活、助学隐私、科研署名、欠薪与工时、租住成本、医院等候、家庭分工、投资焦虑与退休。首章从地图或人生故事集开启，后续到期跨周回访；先前选择改变回访叙述及完结后留下的能力。

每章预约消耗1次行动，选择不重复收费；现金不足的选择被阻止且不改变状态。助学、援助与欠薪沿用跨周办理和真实账本。用完行动隐藏提示。章节阅读和结果确认都自动保存，刷新可以继续；完结故事支持免费回看。旧存档兼容升级，不替玩家补做选择。

使用内置image_gen生成6张新剧情画：夜间宿舍、深夜工作、医院等候、共同餐桌、行情之后的茶室、人生车站。1672×941原始分辨率，PNG转无损WebP经过解码像素一致性检查；界面使用contain完整构图。全部22则原有人生事件也增加适配插画、环境叙述与人物对白。素材路径和完整提示词见story-art-v3.2.json。

验证：145项逻辑测试；109项高中回归、57项人生界面/交易、52项新剧情与画面、6项真实人生旅程，共224项浏览器检查。覆盖320/390/768/1440与844×390横屏、12周支线实际完结、208周主线、选择分支、刷新恢复、旧档、资金不足、纯回看、耗尽行动提示隐藏。启动重试、GitHub子路径和离线打开也通过。生产验证与资源哈希见deployment.json。
