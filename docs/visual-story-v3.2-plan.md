# v3.2 画风与叙事升级

大学、社会此前使用重复的细线叶子导航与过密的信息卡，与高中既有彩色手绘图标不一致。本次沿用GameIcon的64×64笔触、轮廓和配色，新增指南针、工牌、行情、医疗包、保障、报纸、手柄、烧瓶、列车与闹钟10种图标，覆盖导航、地点、资源、工作、检查与长期任务。界面增加纸张层次、卡片插画、留白与分组，不把技术说明当作剧情。

人生新增一条主线与八条四章支线，共36章；每章包含场景叙述、人物对话、两种选择及独立后果。第一选择保存在存档中，改变之后的回访叙述和完整故事所保留的能力。主线至少208周，支线至少12至24周，有读前条件、跨周等待、回访、结果确认与免费回看。

每章消耗1行动，选择不会再次扣除。后续到期的已启动故事在周初回访，尚未启动的故事在地图与故事集中提示；用完行动后隐藏可进行角标。阅读期间、选择后结果页均保存，刷新可继续；旧档增加空故事状态而不替玩家做决定。助学、欠薪、援助沿用真实账本和跨周审核，剧情不制造欠薪，不替代检查、治疗、交易、登记结婚或相处确认。

素材采用内置imagegen生成六张独立16:9剧情插画：宿舍夜谈、深夜办公室、医院等候、共同餐桌、行情之后的茶室与人生车站。既有地图仅作为画风参考；人物明确成年，玩家位置采用空椅和第一人称桌面，兼容自定义名称与男女主。完整原图、提示词、生成路径、尺寸、哈希与无损WebP记录保存于story-art-v3.2.json，场景图不裁剪、不缩小。

验收覆盖：320/390/768/1440与横屏，图标差异、地点/故事提示不重叠、长标题完整、模态框边距、触屏地图；实际完成阅读、跨周回访、刷新恢复、支线完结回看、旧档迁移、拒绝非法进度和资金不足选择，以及原有交易/医院/家庭回归。
