# v3.4.0 · 围墙之外，也有完整的故事

高中、大学、社会共用固定的大地图总览。原图按屏幕可用空间完整适配，地标在图内避让，九个高中区域、四个大学区域、七个社会区域均可直接进入。总览没有缩放、拖动或滚动目录；窄屏采用紧凑地标，横屏将世界选项放在侧边。区域小地图继续保留拖动、缩放与边缘入口。删除界面上的资源分辨率与原图调试链接。

后续剧情、人物对话、选择预览与结果恢复原有手写字体。人物说话条使用独立样式，避免继承高中人物头像的负上边距；人生选项样式也限定在阅读器内，不再覆盖高中剧情。玩家发言使用自定义姓名与所选男女主头像。章节按现场、对话、回应阅读，可返回上一页；选定回应后可修改，最终确认才结算一次。

人生故事集从9条36章扩充为15条60章。新增求职与面试、保险条款与材料流转、夜街朋友、大学社团与公共空间、家庭育儿、离职与重新开始六条四章支线，跨越8至16周。每章包含独立的现场描写、连续人物对话与两种回应。原有36章增加独立场景与人物发言，后续章节根据最近一章的选择展示不同叙述，并将结果写入回忆；最初选择的长期回声继续保留。

每章仍只使用一次行动，阅读、返回、预览及刷新不重复扣除。后续章节保持真实周数等待；求职故事不直接发放工作，保险故事不伪造购买或赔付，育儿要求已有孩子，离职故事要求真实工作经历且当前未在职。保持原有故事标识、四章进度与存档结构，已完成旧故事不会重新开启。

验证：160项逻辑测试通过，包含六条新增支线两组选择的实际跨周完成、第二章选择影响第三章与保存结果、旧进度恢复、条件限制与窄屏地标排列。147项浏览器检查通过，覆盖1440×1000、1280×720、390×844、320×568、844×390；包含三张地图的完整图像、全部地标、按钮间距、无滚动与无缩放、免费传送、字体、角色头像、选择预览、单次结算及刷新恢复。TypeScript、288所院校数据与生产构建通过。部署记录见 deployment.json。

两个 pages.dev 站点及 GitHub Pages 均通过相同的147项线上检查，三个入口的脚本、样式、缓存清单和剧情图像已经核对。GitHub 构建的缓存清单条目顺序与 Windows 构建不同，资源集合相同，脚本、样式与图像字节一致。
