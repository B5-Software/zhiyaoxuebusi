# v3.1 逻辑完善计划（2026-10-09）

本次针对 v3.0 的系统衔接缺口，不把已有入口与图片当作逻辑完成的证据。已生成的两张世界图、11 张区域原图继续使用，保持原始尺寸。

## 已确认的问题

工资延迟事件没有真的延迟工资；伴侣每周固定提供 210，未记录劳动；无钱支付生活费仍总能形成欠款，却不影响饮食与休息；退休未检查缴费经历。自动日程优先课程会漏掉学生的工作。大学毕业使用人生总周数，未区分实际入学时点。孩子到 22 岁直接获得本科，继承时重建身体和学历。疾病检查依赖文字匹配，诊断、复查与治疗缺少持续状态；癌症治疗之后只要一次付费就可以永远改善。合约仅看周末价格，没有周内波动与保证金调整。事件库耗尽后人生长期空白。区域入口只打开同一份列表，三个交易入口也没有区分对应页签。

## 实现顺序及验收

1. 共同日历：高中、大学、社会、角色相处和孩子继承使用同一绝对周。大学按实际入学周、208 周与 160 学分毕业。下一代未上高中跳至 15 岁，已经上高中保留当前年龄；高中阶段不能访问成人专属入口。孩子自己的学习记录、技能与身体保留，上一代伴侣归档。
2. 劳动与账本：学生岗位按兼职工时计薪；大学课程与工作同时进入日程。工资、欠薪、追索、解约、退休缴费周数明确结算。生活缺口影响饮食、疲劳和压力，可申请有冷却和办理时间的援助。
3. 事件因果：房租上涨是持续支出，欠薪变成应收和追索任务；助学、投诉、医疗援助需要跨周办理。优先未读事件，耗尽后只允许符合条件和长冷却的日常事件。人生阶段、家庭、工作和医院分别有事件与里程碑。
4. 生理与医院：内环境增加血糖、糖化、血压、血常规、肾功能、氧合与疲劳指标，状态为代偿、负荷、失代偿、危急。病程仍只包含指定 12 类。检查记录保存数值和疑似／确认目标，不能靠一段提示文字解锁诊断；必要时跨周复查。慢病、康复、肿瘤疗程、随访和停药各自推进。报销起付累计按模拟年度结算，等待期和既往病况条款保留。
5. 家庭与世代：伴侣收入取决于岗位、可用工时、照护分担与退休；孕育期间、出生、幼儿、学龄和成年有不同费用与责任。分开不删除孩子或终止共同孕育照护。孩子逐年积累自己的教育与身体记录，成年也可能未就业、未取得本科。遗产先清偿债务，再记录伴侣份额和孩子份额。
6. 市场：现货成本与已实现盈亏明确记录；逐仓合约检查周内不利价格，资金费、交割、追加与减少保证金有账本记录；AMM/LP 保持资产守恒。不同地点进入股票、Crypto 合约或 Uniswap 对应页面。
7. UI 与验证：所有操作有明确消耗、条件和结果；选中的地点打开对应操作。人物／账本／医院提供时间与后续提示，按钮分组、换行。验证连续多年度、贫困、欠薪、怀孕分开、治疗复查、失业、旧档迁移和下一代不同年龄，不只检查按钮存在。

游戏病程速度、诊疗收费、招聘门槛、援助及报销规则均为虚构参数。参考材料用于避免基本机制错误，并不将模拟数值当成现实医学、投资或办事规则。
