# v3.0.0：围墙之外的人生

高中毕业后可以进入大学与社会，随时免费返回高中地图。三张大地图共享一条持续推进的年龄、行动与身体时间线。旧存档保留高中任务、人物关系和已有回忆，自动补齐人生状态。

新增大学与社会两张大地图，以及 11 张独立绘制的区域小地图：教学图书馆、宿舍食堂、科研实习、湖畔文体、人才市场、工作街区、交易所、医院、保险办事大厅、夜生活街区、住宅生活。所有新图保留生成资源的原始分辨率，采用无损 WebP；没有从大地图裁切小地图。地图默认 150%，支持拖动、双指缩放、屏幕外地点箭头与完整原图查看。区域预览完整显示图片。

- 大学课程每周推进，取得本科需要至少 208 周和 160 学分；学历、学校背景、技能与互动面试共同影响 8 类岗位的招聘。排班消耗体力，工资与账单在周末结算，连续缺勤影响合同。
- 5 个可实际操作的小游戏：记忆翻牌、逻辑解题、节奏练习、一周预算、互动面试。中途状态可恢复，每种每周一次。
- 本地模拟股票、Crypto 现货、逐仓永续与四周交割合约，以及 Uniswap v2 常数乘积池。交易记录本金、手续费、保证金、资金费、到期结算、强平与 LP 份额。
- 恋人与家庭面板支持毕业后相处、主动表白、同行、双方求婚确认、登记、孕育或共同养育计划、孩子成长和分开后的照护。大学期间达到婚龄和双方条件后可结婚。
- 身体保存高中饮食、睡眠、活动与累积负荷，七类内部储备相互影响。仅包含需求指定的 12 类疾病，区分潜伏、症状、确诊、进展、稳定治疗与急症。化验发现线索后再做进一步确认；治疗、保险、长期随访和医疗欠款进入账本。概率与收费均为游戏参数。
- 病死、寿终与意外终章可结算或继续孩子的人生。未成年孩子跳至成年高三，成年孩子保留当前年龄；上一代伴侣关系不会被继承。
- 8 项人生长任务，以及 16 段优先未读且按条件触发的现实事件。账本提供 4、13、52 周日程推进，遇到剧情、身体提醒、急症或终章会停下。
- 新阶段有六页游玩指引，保留通讯、存档和 30 分钟休息提醒。弹窗、表单、导航与地图适配手机、平板、桌面和短横屏；修正 IM 特殊入口与消息操作按钮的间距。

验证：111 项逻辑测试、TypeScript 检查、生产构建；浏览器检查见 `life-browser-checks.json`，加载与断网检查见 `loading-path-checks.json`。原图来源和尺寸见 `life-art.json`，设计及参考资料见 `lifetime-plan.md`。
